# Release notes for sbmlsim 0.18.3
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

The task types of simrun run on simrun 0.2.0. Results do not change.

## Dependencies

- **simrun 0.2.0** ([#482](https://github.com/matthiaskoenig/sbmlsim/pull/482)). The `simrun` extra requires `simrun>=0.2.0` and the lock takes simrun 0.2.0, which runs a workflow on the local machine (`simrun submit --local`) with the same task types `sbmlsim.<kind>` as on the cluster, and merges a split task in its coordinator instead of a merge pod. The task types of sbmlsim are unchanged.
