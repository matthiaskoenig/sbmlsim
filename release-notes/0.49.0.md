# Release notes for sbmlsim 0.49.0
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

The chart builder is a module of sbmlsim-core 0.34.0, `sbmlsim_core.chart`, which pkpdutils and pkdb draw their figures with; `sbmlsim.plot.chart` and `sbmlsim.plot.colors` re-export it.

## Changes

- **The chart builder of sbmlsim-core** (#695). `sbmlsim.plot.chart` (`Chart`, `ChartPlot`, `ChartAxis`, `LEGEND_LOCS`, `MARKERS`), `sbmlsim.plot.colors` and the thinning of dense curves moved into the python package of sbmlsim-core 0.34.0 as `sbmlsim_core.chart`, so the packages below sbmlsim (pkpdutils, pkdb) draw charts without depending on sbmlsim. sbmlsim re-exports every public name; the re-exports load the bindings of sbmlsim-core on first use, so `import sbmlsim.project` still loads none (`tests/test_imports.py`). `docs/plotting.md` keeps the figures of sbmlsim and points to `docs/chart.md` of sbmlsim-core for the chart builder.
- **sbmlsim-core 0.34.0** (#695): the renderer of the fourth round of the ported figures of pkdb_models (legends of the figure above the grid and under a column, fonts and frames of every legend, edges of bars, the opacity of a box median, the drawing order across both y axes, colour bars below the grid, images).
- A data array with a unit pint does not know, on an axis without a unit, is drawn as given instead of raising: units are read only for a conversion.
