# Release notes for sbmlsim 0.26.0
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

The documentation of a model release shows the figures of the model as a reader meets it: the overview of the body with the bodies first and the schematic of the compartments second, and the index of its site embeds the interactive figure of a diagram, with its hover cards, instead of the static image. sbmlsim simulates SBML level 3 only and converts a model below it when it is loaded, so a model of an older level runs on every engine.

## Features

- **The index of a model repository shows the interactive figures** ([#530](https://github.com/matthiaskoenig/sbmlsim/pull/530)). The release copies the HTML files which the factory writes beside its models, the interactive snippet of a diagram (`<stem>.html`, one `<div>` with the figure, its hover cards and its script, everything scoped to that `<div>`), and the index embeds the snippet of a diagram instead of its image. The README, which GitHub shows without scripts, keeps the SVG, and so does the models page; a model whose factory writes no snippet is unchanged. pkpdsim writes the snippets of its models with `interactive_figure(..., snippet=True)`.
- **The diagrams of a model in the order of `DIAGRAM_ORDER`** ([#530](https://github.com/matthiaskoenig/sbmlsim/pull/530)). The README and the index show the overview of the body with the bodies first (`<model>_body.svg` of the PBPK library of pkpdsim, `<model>_anatomy.svg` of its machine perfusion library), then the schematic of the compartments (`<model>.svg`), then any other diagram of that model by its name; they followed the order of their file names, which showed the schematic first.
- **A model below SBML level 3 is converted at load** ([#529](https://github.com/matthiaskoenig/sbmlsim/pull/529)). sbmlsim simulates SBML level 3: a document of a lower level is converted when it is loaded, for every engine, and a conversion which libsbml logs an error for is refused, since it drops what the level cannot hold. Every case of the SBML Test Suite runs in level 3 version 2 with the conversions cached, and the pages state which conversions are refused and which cases roadrunner cannot integrate.

## Fixes

- **The project of the published install with uv is named** ([#528](https://github.com/matthiaskoenig/sbmlsim/pull/528)), since `uv init` refused a temporary directory whose name ends with an underscore.
