# Release notes for sbmlsim 0.52.0
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

The global sensitivity analysis runs in Rust in sbmlsim-core 0.37.0 and SALib is no runtime dependency any more; the PEtab export writes a training and a validation problem with a README of its gaps; the equations of a release archive come from sbmlsim-core.

## Sensitivity analysis

- **The global sensitivity analysis runs in sbmlsim-core 0.37.0** (#706): the designs
  `sampling.sobol`, `sampling.fast` and `sampling.morris` and the estimators of
  `sensitivity.sobol`, `sensitivity.fast` and `sensitivity.morris` are the ones of
  SALib in Rust, every element of an output on every CPU. SALib is no runtime
  dependency any more.
- The points of a seed change: sbmlsim-core draws with a generator of its own,
  the same on every platform and in WebAssembly, so a design of a seed has other
  points than before, and the intervals (`S1_conf`, `ST_conf`, `S2_conf`,
  `mu_star_conf`) of a seed are other resamples of the same bootstrap. Results of
  0.50 are not reproduced by their seed. The bootstrap of FAST is seeded with the
  seed of the design.
- FAST estimates its intervals 7x faster (0.15 s for 1000 elements of five
  parameters).

## Changes

- **PEtab export** (#710): `to_petab` and `PetabExporter` write a README of every export (the fit, the values it starts from, the settings, the parameters, the data and what PEtab does not express), `to_petab_problems` a training problem and a validation problem, and the run kind of an export skips the mappings PEtab cannot express instead of failing; the extension version is 0.6.0.
- **Release archives** (#709): the equations in Markdown of a release archive are generated by the shared Rust core of sbmlsim-core; sbmlode is no dependency any more.
- **Fits** (#707): the jacobian of a formula of a pinned target is the exact one of the engine, with sbmlsim-core 0.37.0, which carries the derived values of a condition by its sensitivities (sbmlsim-core#138); a tightened test checks it.
- The floor of sbmlsim-core is 0.37.0 (#706); its markers are compact in PDFs and `error_cap` is matplotlib's `capsize` (a cap twice as long as before).
