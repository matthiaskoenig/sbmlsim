# Release notes for sbmlsim 0.8.2
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

A patch release of the output of a run: the report of simulation experiments ends the output with a link which the terminal opens with a click.

## Features

- **the report of simulation experiments ends the output with a link** ([#236](https://github.com/matthiaskoenig/sbmlsim/issues/236), [#238](https://github.com/matthiaskoenig/sbmlsim/pull/238)). A run of simulation experiments ended in a log line with the path of the report, which the terminal broke into lines and did not open. `ExperimentReport.create_report` ends the output with the section of the report, as the report of a fit does: the number of experiments and the link to the report. `show_report=True` opens the report in the web browser, also through `run_experiments`; the log line of the report is a debug message
- **`sbmlsim.display` is the output of scripts**: the sections, the key/value blocks and the links of the console output of a fit, which `sbmlsim.fit.display` provides as before. A link is a hyperlink of the terminal (OSC 8), which VS Code, iTerm2, Windows Terminal, GNOME Terminal and kitty open with a click whatever the width of the terminal; its text is the `file://` URI on a single line, which a terminal without hyperlinks recognizes and which ends up in a log

## Fixes

- a link starts in the column of the values of a key/value block, it was one column to the left
- `sbmlsim.report.experiment_report` is importable on its own; it imported the experiments, which import the runner, which imports the report
- the context managers of the fit runner are annotated as `Generator`, which ty 0.0.85 requires

## Development

- tox of the `dev` extra creates its environments with uv, as the continuous integration does: pip ended in `ResolutionImpossible` for the dependencies on python 3.14 ([#235](https://github.com/matthiaskoenig/sbmlsim/pull/235))
