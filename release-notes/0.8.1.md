# Release notes for sbmlsim 0.8.1
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

A patch release of the data paths of a fit: the report, the console of a fit and the JSON of an experiment show them as paths again, and the overview of a fit report lists only the experiments the fit uses.

## Fixes

- **the data path of a fit is shown as paths** ([#233](https://github.com/matthiaskoenig/sbmlsim/pull/233)). The data path of the simulation experiments is a path or several paths and is stored as a list, so the overview of a fit report, the console of the fit command and the JSON of an experiment showed the representation of the list, i.e. `[PosixPath('/data')]`, instead of the path. `sbmlsim.utils.paths_text` writes one path per line, which the key-value lists of the HTML reports keep, and the JSON of an experiment has `data_path` as a list of strings
- **the overview of a fit report lists the experiments with fit mappings.** It listed every experiment with a collection, also those whose mappings are all excluded by the selection of the problem; it lists the experiments with fit mappings now, as the data table of the report does
- `data_path` of `FitDefinition`, `OptimizationProblem`, `ExperimentRunner`, `FitMappings` and `select_mapping_collections` is annotated as one or several paths, which the simulation experiments always accepted

## Documentation

- the citation of the README, the documentation index and `CITATION.cff` points at the Zenodo record of 0.8.0 ([#232](https://github.com/matthiaskoenig/sbmlsim/pull/232))
