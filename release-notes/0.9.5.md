# Release notes for sbmlsim 0.9.5
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

A patch release of the fixes which the port of the models of pkdb_models onto sbmlsim 0.9.4 found.

## Fixes

- **The processes of a pool end with the process which started it** ([#316](https://github.com/matthiaskoenig/sbmlsim/issues/316)). When the main process of a pool died (a signal, a crash, a killed command), its workers waited for their next task forever, reparented to init, with the memory of their models (about 300 MB per worker for a PBPK model, 3.6 GB for the 20 workers of a sensitivity analysis of the midazolam model of pkdb_models), and kept the forkserver and the resource tracker of multiprocessing alive, until they were killed by hand. A worker now waits in a thread for the sentinel of its parent, which every start method provides, and ends when the parent ended; the forkserver and the resource tracker end with the last process which uses them. Two seconds after `SIGKILL` or `SIGABRT` of the main process no process of its pool is left.
- **The figures of sbmlsim do not depend on the backend of pyplot** ([#317](https://github.com/matthiaskoenig/sbmlsim/issues/317)). With an interactive backend of matplotlib (TkAgg, the default when `DISPLAY` is set), a figure of `pyplot` holds objects of Tk, which the garbage collector releases in whatever thread it runs, e.g. a thread of a pool: Tk then aborts the process (`RuntimeError: main thread is not in main loop`, `Tcl_AsyncDelete: async handler deleted by the wrong thread`, exit 132). The figures of the report of a fit, of the profile likelihood (`plot_profiles`, `plot_profile`) and of `DataSetsComparison.plot_diff` were drawn with `pyplot`; they are now a `matplotlib.figure.Figure`, as the figures of the experiments and of the sensitivity analysis already were, and the report sets its matplotlib parameters with `rc_context`, which does not resolve the backend. A returned figure is not held by `pyplot`, a caller who shows it attaches it to a manager, as `SimulationExperiment.show_mpl_figures` does. The figures of `pkpdsim`'s sampling analysis are drawn with `pyplot` and need the same change there; a run which aborts no longer leaves its pool behind (#316).
