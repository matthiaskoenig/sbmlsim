# Release notes for sbmlsim 0.54.0
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

Every problem of the PEtab benchmark collection runs in sbmlsim-core 0.40.0, which reads comp models, an `<apply>` whose only child is an `<apply>`, and the steady state after a request at a single time.

## Changes

- **The PEtab benchmark in the core** (#717, follows sbmlsim-core#145). `CORE_GAPS` is empty: Armistead (a model of comp), Beer (an `<apply>` without operator) and Blasi (a steady state at `inf` without an experiment) are read and evaluated by sbmlsim-core like the other problems, their llh equal to the one of python to 1e-10; the collection passes 28 of 34 problems as before, the same six for the same reasons. The floor is `sbmlsim-core>=0.40.0`, which also brings the PEtab fit of every prior, of non-linear values of the first period and of infinite bounds, and the fit of a PEtab problem in a page.
