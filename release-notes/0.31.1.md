# Release notes for sbmlsim 0.31.1

The renderer of the web pages is sbmlsim-web 0.4.1, which draws the panels of a model without an uncertainty again.

## Fixed

- **A panel of a model without an uncertainty drew no curve** ([sbmlsim-web #8](https://github.com/matthiaskoenig/sbmlsim-web/pull/8)). The service answers `uncertainty: null` for a panel whose model carries none, and the renderer of 0.4.0, which 0.31.0 vendored, read only the field a service before 0.30 leaves out: it threw where it should have asked for no draw, and every panel of every model without a fit showed nothing. The static pages of such a model, which carry the renderer in them, drew nothing either. The vendored renderer is 0.4.1, which asks for no draw of both spellings.
