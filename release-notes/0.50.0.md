# Release notes for sbmlsim 0.50.0
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

Data between the points of a scan and a fitted parameter which the dimension of a scan sets are a fit of the engine on sbmlsim-core 0.35.0, the figures of a run over the draws are built faster, the forkserver of a pool preloads the experiment classes it imported, and sbmlsim takes pkpdutils 2.0.0, which draws without matplotlib.

## Features

- **Data between the points of a scan in the engine** (#696, follows #624). A mapping over a dimension whose data lie between the points of the scan is a curve of `fit/1` over the points of the dimension, `dimension: {conditions, values, x}`, which the engine interpolates with the arithmetic of `numpy.interp`; a fitted parameter whose target a dimension without `at` sets is `pinned` in the conditions of its points, so the dimension wins as in python and the column of the parameter is zero there. The residuals equal the ones of python on linux and differ by a few ulps on other platforms. A formula before the simulation which reads a pinned target stays the gap `scan`. The floor is `sbmlsim-core>=0.35.0`.
- **`SimulationExperiment.preload_in_forkserver`** (#697). The forkserver of a pool imports `sbmlsim._forkserver` last, which calls this classmethod (nothing by default) on every experiment class it imported, so the workers inherit what a class loads there; an error of one is logged. pkpdsim loads the builds of the equilibration of its PBPK experiments with it.

## Changes

- **The figures of a run over the draws** (#698). The bands of a figure share one grid per x (`Grids`), the two quantiles and the median of a band sort once, and a curve which selects one point of one task (the line of a draw) is indexed with numpy in the arrays read once per figure (`Data.selected_values`) instead of `isel`: the figures of the dose dependency of HCTZ over 100 draws are built in 1.3 s instead of 6.7 s, the outputs byte for byte the same.
- **pkpdutils 2.0.0** (#700), whose figures are charts of sbmlsim-core without matplotlib.
