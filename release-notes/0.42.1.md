# Release notes for sbmlsim 0.42.1
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

The colours of a figure are the names matplotlib takes, `grey` for `gray` included.

## Fixes

- **`tab:grey` and the other spellings of grey** (#670). Since 0.42.0 the colours of a style are normalized without matplotlib (`sbmlsim.plot.colors`), and the normalization refused `tab:grey`, which matplotlib takes: the experiments of aliskiren, apixaban and lenvatinib of pkdb_models no longer initialized (`ValueError: unknown colour 'tab:grey'`). The names of matplotlib (`matplotlib.colors.get_named_colors_mapping`) also spell a tableau name of `gray` with `grey` and an xkcd name of `grey` with `gray`, the latter winning over an xkcd name of `gray` of the table; `sbmlsim.plot.colors` takes the same names now, which a test checks against every name of matplotlib.
