# Release notes for sbmlsim 0.9.1
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

A patch release of the dependencies: pip installs the `sciml` extra on python 3.14 again.

## Dependencies

- **`pydantic>=2.12` instead of `pydantic>=2.13.5`, and `pymetadata>=0.8.1`** ([#288](https://github.com/matthiaskoenig/sbmlsim/pull/288)). On python 3.14 pip can install only the 9.x releases of `pydantic-numpy`, which `petab-sciml` needs through `mkstd`, and they require `pydantic~=2.12.5`. sbmlsim and pymetadata 0.8.0 required `pydantic>=2.13.5`, so `pip install "sbmlsim[sciml]"` failed on python 3.14 with `ResolutionImpossible`, as described in the release notes of 0.9.0. Both lower bounds were the newest release when the bounds were pinned, not a requirement: pymetadata 0.8.1 requires `pydantic>=2.12`, and the tests of sbmlsim pass with pydantic 2.12. uv was not affected.
