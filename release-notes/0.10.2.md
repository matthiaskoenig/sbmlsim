# Release notes for sbmlsim 0.10.2
![sbmlsim](https://github.com/matthiaskoenig/sbmlsim/raw/develop/docs/images/favicon/sbmlsim-100x100-300dpi.png)

A release of the dependencies: sbmlsim does not install libroadrunner 2.11, which breaks the simulator. The simulations and the fits are unchanged.

## Dependencies

- **libroadrunner < 2.11** ([#351](https://github.com/matthiaskoenig/sbmlsim/pull/351)). libroadrunner 2.11.0 breaks 26 tests of the simulator, the root tolerance of the integrator and the rows of the events, which sbmlsim 0.10.0 and 0.10.1 installed with it since their dependency had no upper bound. The dependency is `libroadrunner>=2.10.0,<2.11` until the work on libroadrunner 2.11 lands.
